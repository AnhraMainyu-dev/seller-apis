# Обновление остатков и цен на маркетплейсах Ozon и Яндекс-Маркет

Проект помогает автоматически поддерживать актуальность товаров магазина Casio на двух площадках:
Ozon и Яндекс Маркет. Он автоматически проверяет наличие товаров и изменения цен магазина и корректирует данные 
на маркетплейсах.

### Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, если есть конфликт с Python2) для установки зависимостей:

`pip install -r requirements.txt`
### Как использовать

В проекте два скрипта, по одному на каждый маркет-плейс.
Скрипты скачивают свежий каталог с сайта Casio, в котором указаны код товара, его остаток в наличии и идентификатор.
Скрипт запрашивает у площадок данные об уже созданных товарах, сверяет их с актуальным каталогом и 
корректирует несовпадающие данные.

Скрипт не создаёт новые карточки товара.
